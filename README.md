# 🎂 Romantic Birthday Surprise Website 💖

A personalized birthday gift website crafted with aesthetic glassmorphism, animated heart trails, interactive memories gallery, love letters, a 3x3 reveal game, and a blowable birthday cake finale with confetti!

---

## ✨ Features

1. **Scene 1: Welcome & Typing Effect**
   - Glowing glassmorphic welcome card with typewriter animation for `"Happy Birthday"`.
   - Romantic aesthetic anime visual with warm golden sunset glow.
   - Interactive pink neon heart particle trail following cursor and touch gestures.

2. **Scene 2: Birthday Memories Gallery**
   - 6 aesthetic memory cards with hover zoom, 3D tilt, and interactive lightbox preview.
   - Personalized message for the recipient with glowing highlights.

3. **Scene 3: A Love Note**
   - Realistic lined notebook parchment card with handwriting font.
   - Matches the heartfelt message from the video (customizable directly or via settings).

4. **Scene 4: Why You're Special (3x3 Flip Card Game)**
   - 9 interactive 3D flip cards with question marks (`?`).
   - Flips to reveal heartwarming reasons with chime sound effects.
   - Live progress counter and celebration fireworks when all 9 are unlocked!

5. **Scene 5: Happy Birthday Wishes**
   - Romantic couple under starlight illustration with sweet birthday message.
   - Leads to the secret lock screen via `"One Last Secret 🔒"`.

6. **Scene 6: One Secret Left (Passcode Keypad Lock)**
   - 3D Gift box icon floating with a soft bounce.
   - Glassmorphic card with numeric keypad (`0-9`, delete, enter).
   - 4 glowing PIN dots that light up as digits are entered.
   - If wrong: shakes with `"TRY AGAIN ❌"` feedback.
   - If correct: unlocks with celebration sounds, confetti, and reveals the Grand Finale Birthday Cake!
   - Default PIN is `1234` (can be changed anytime in the ⚙️ Settings).

7. **Interactive Birthday Cake Modal**
   - Tap/click the candle to blow out the flickering flame!
   - Triggers smoke puff, celebration fanfare sound, full-screen colorful confetti shower, and reveals the eternal promise card.

8. **Background Romantic Music Player**
   - Click the 🎵 music icon at the top right to start a soothing music-box / acoustic piano melody synthesized with the Web Audio API (works 100% offline, no broken links).

9. **In-Browser Personalizer (⚙️ Settings button)**
   - Click the ⚙️ icon in the top right corner to edit recipient name, signature, secret 4-digit passcode, hint, and love note without touching any code. Changes save instantly to `localStorage`.

## 🖼️ Apni Marzi Ki Images Kaise Lagayein? (How to Add Your Own Photos)

Apni photos lagana bohot hi asaan hai:

### Tareeqa 1 (Sab se asaan tareeqa - No Coding Needed!):
Aap apne computer mein is folder me jayein:
`c:\Users\hamza\Downloads\Birthday\assets\`

Wahan pe ye 8 photos hain:
1. `hero_girl.jpg` — **Pehle welcome page ki photo**
2. `memory_1.jpg` — **Gallery ki 1st photo**
3. `memory_2.jpg` — **Gallery ki 2nd photo**
4. `memory_3.jpg` — **Gallery ki 3rd photo**
5. `memory_4.jpg` — **Gallery ki 4th photo**
6. `memory_5.jpg` — **Gallery ki 5th photo**
7. `memory_6.jpg` — **Gallery ki 6th photo**
8. `couple_final.jpg` — **Page 5 ki couple photo**

👉 **Aapko bas apni photos ko `assets` folder mein copy karna hai aur unka name upar wale names ke mutabiq rakh dena hai (maslan `hero_girl.jpg`, `memory_1.jpg`, etc.)!**
Uske baad website refresh karein, aapki real photos show ho jayengi!

### Tareeqa 2 (Agar aapke pass different file names hain, e.g. `.png`):
Apni photos ko `assets/` folder mein dalein (e.g. `assets/my_pic.png`), aur [index.html](file:///c:/Users/hamza/Downloads/Birthday/index.html) file khol kar `src="assets/hero_girl.jpg"` ko badal kar `src="assets/my_pic.png"` kar dein.

## 🔑 Secret Passcode Kaise Badlein?
- Website pe upar right corner mein **⚙️** icon par click karein.
- **"Secret Code (4 digits)"** mein apni marzi ka koi bhi 4-digit code likhein (maslan uski birth date, year, ya koi bhi code).
- **"Passcode Hint for Her"** mein hint likhein jo usko nazar aayegi.
- **Save & Apply Changes** par click karein!
